# Documentation

This directory contains supporting documentation for the reproducibility package accompanying the ACIJ manuscript:

**Variable-Level Causal Reliability from Heterogeneous Causal Discovery Methods in Multivariate Time Series**

## Files

- [`DATA_AVAILABILITY.md`](DATA_AVAILABILITY.md) — provenance and availability of the synthetic, Lorenz-96, and CausalTime data used in the study.
- [`RESULTS_CHECK.md`](RESULTS_CHECK.md) — verified publication-gate counts and the main numerical results reported in the revised manuscript.
- [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) — instructions and constraints for reproducing the experimental workflow.
- [`UPLOAD_CHECKLIST.md`](UPLOAD_CHECKLIST.md) — final repository checklist before changing repository visibility from Private to Public.

For executable code, see the repository's [`code/`](../code/) directory.  
For archived experiment outputs, see [`results/`](../results/).
