# Repository Publication Checklist

Before changing the repository from Private to Public, confirm:

- [x] Root `README.md` is updated.
- [x] `CITATION.cff` is present.
- [x] `requirements.txt` is present.
- [x] Reproducibility notebook is present under `code/`.
- [x] Python source analogue is present under `code/`.
- [x] `code/README.md` is updated.
- [ ] `docs/` documentation files are uploaded.
- [ ] `results/` archived outputs are uploaded.
- [ ] No API keys, passwords, tokens, credentials, or private personal files are present.
- [ ] CausalTime benchmark files are not redistributed unless permitted by the upstream license.
- [ ] Repository contents match the final manuscript.
- [ ] Repository is reviewed once more before switching visibility to Public.
